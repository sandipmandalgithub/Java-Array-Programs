# Java Array Programs

This repository contains Java programs demonstrating **Arrays** and commonly used array operations.

These programs were created for practicing and understanding how arrays are used to store and manipulate multiple values of the same data type in Java.

## 📚 Concepts Covered

### One-Dimensional Arrays

* Array declaration and initialization
* Accessing array elements
* Array traversal
* Finding maximum and minimum values
* Calculating sum and average
* Searching elements
* Sorting arrays

### Two-Dimensional Arrays

* 2D array declaration and initialization
* Matrix representation
* Traversing rows and columns
* Matrix operations

### Common Array Operations

* Inserting and updating elements
* Searching elements
* Sorting elements
* Reversing arrays
* Finding duplicate elements
* Finding unique elements

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run the program as a Java Application.
